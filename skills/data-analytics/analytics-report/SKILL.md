# Analytics Report

## 任務目標
- 本 Skill 用於：規範資料分析報告輸出標準
- 能力包含：標準報告結構、讀者分層策略、輸出模板、撰寫規範
- 觸發條件：需要輸出分析報告、呈現分析結論時

## 適用場景
- 需要把分析結果寫成面向管理層、執行層或學習者的報告
- 需要統一報告結構、圖表表達和行動建議格式
- 需要把結論、證據和建議組織成可交付文字

## 標準報告結構

### 核心原則：結論前置

**為什麼結論前置？**
- 決策者時間有限，需要快速獲取關鍵資訊
- 讓讀者帶著結論看細節，更有針對性
- 體現分析師的專業性和價值

## 讀者分層與策略

### 四類讀者模型

| 讀者型別 | 特徵 | 關注重點 | 報告策略 |
|----------|------|----------|----------|
| A類 | 高層+瞭解業務 | 宏觀+業務痛點 | 結論前置，趨勢圖表為主 |
| B類 | 執行層+瞭解業務 | 微觀+運營問題 | 詳細分析過程，細節資料 |
| C類 | 高層+不瞭解業務 | 戰略+方向診斷 | 背景詳述，結論明確 |
| D類 | 新人+學習目的 | 業務細節+指標定義 | 背景充分，邏輯清晰 |

### 針對A類讀者（決策層）
```
標題：XX業務診斷與戰略建議
結構：
- 結論與建議（佔40%篇幅）
- 業務背景簡述（1-2段）
- 核心指標監控資料（趨勢圖）
- 競品對比（如有）
- 風險預警（如有）

圖表：趨勢圖、KPI儀表盤、對比圖
語言：簡明扼要，避免過多技術術語
```

### 針對B類讀者（執行層）
```
標題：XX運營問題深度分析
結構：
- 分析目標（明確）
- 資料選擇（微觀資料）
- 分析過程（詳細）
- 結論與建議（可落地）

圖表：明細資料、維度拆解圖、漏斗圖
語言：專業但不晦澀
```

### 針對C類讀者（高層外行）
```
標題：XX業務發展分析報告
結構：
- 業務背景詳述
- 分析依據充分
- 結論定性總結
- 建議方向明確

圖表：直觀易懂的視覺化
語言：通俗易懂，適當類比
```

### 針對D類讀者（學習者）
```
標題：XX業務分析案例
結構：
- 業務背景詳述
- 指標定義說明
- 分析步驟詳細
- 結論有推導過程

圖表：邏輯清晰的流程圖
語言：詳細解釋，便於學習
```

## 撰寫規範

### 標題規範
```
格式：[業務/主題]+分析型別+報告
示例：
- "2024年Q1使用者留存問題診斷報告"
- "618大促活動效果分析報告"
- "競品對比分析月報"
```

### 數字使用規範
| 場景 | 規範 | 示例 |
|------|------|------|
| 數量 | 使用阿拉伯數字 | 1000、52.5% |
| 百分比 | 保留1-2位小數 | 52.3% |
| 金額 | 註明單位 | 100萬、1.5億 |
| 範圍 | 使用"至"或"-" | 10%-20% |
| 對比 | 明確基準 | 環比+15%、同比-8% |

### 圖表規範
```
圖表必備元素：
1. 標題：清晰描述圖表內容
2. 圖例：說明資料系列
3. 座標軸標籤：註明單位和含義
4. 資料來源：註明資料出處
5. 註釋：解釋異常資料

圖表編號：圖1、圖2、表1、表2
圖表引用：如圖1所示、如上表所示
```

### 語言風格
| 要素 | 要求 |
|------|------|
| 簡潔 | 刪除冗餘詞彙 |
| 準確 | 用詞精準，避免模糊 |
| 客觀 | 基於資料，避免主觀 |
| 可行動 | 結論要可執行 |

### 常見問題

**問題1：結論不明確**
```
❌ 不好：使用者增長有所提升
✅ 更好：2024年Q1新使用者環比增長15%，主要得益於XX渠道
```

**問題2：建議不可落地**
```
❌ 不好：建議加強運營
✅ 更好：建議在XX渠道增加30%投放預算，預計帶來X萬新增使用者
```

**問題3：資料與結論脫節**
```
❌ 不好：資料顯示A產品在漲
✅ 更好：A產品銷量環比+25%，主要受益於XX功能上線（貢獻度40%）
```

## 質量檢查清單

### 提交前必查
- [ ] 結論是否用量化語言？
- [ ] 每個結論是否有資料支撐？
- [ ] 建議是否可落地執行？
- [ ] 圖表是否清晰易懂？
- [ ] 資料來源是否標註？
- [ ] 術語是否一致？
- [ ] 是否有拼寫/格式錯誤？

### 結構檢查
- [ ] 結論是否前置？
- [ ] 結構是否清晰？
- [ ] 邏輯是否連貫？
- [ ] 受眾是否合適？

## 注意事項
- 報告是給人看的，要考慮讀者背景
- 沒有放之四海的標準，只有是否滿足受眾需求
- 分析師需要清楚：誰看報告、讀者期望什麼、信任度如何
